CustomTools

A lightweight Windows system-tray utility with no main window — its entire menu is built dynamically from plugins you drop into a folder.

Download for Windows View on GitHub

How it works

CustomTools is a thin host built around a plugin contract — it never knows about a plugin's implementation, only that it returns menu items.

CustomTools (tray host) → CTPlugins (contract) ← CTRegistryTree (plugin)

Drop a DLL implementing ICTPlugin into the Plugins/ folder and it's picked up automatically — no registration list to edit.

Key features

🔌 Plugin architecture

The host discovers and loads any plugin DLL in Plugins/ at startup — no code changes needed to add features.

🌳 Registry tree menu builder

Build a nested tree of menu items that run a command, open a URL, open a file, or act as a plain submenu.

🛠️ Built-in editor

A management dialog for the tree — add, edit, remove, and reorder by nesting, all in one window.

📦 Import / export

Back up or share your entire menu tree as a single XML file.

🌐 Localization

English, Polish, German, Spanish, and Italian UI — switch anytime, no restart needed.

⬆️ Auto-update

Checks GitHub for new releases on startup and daily. Install, snooze, or skip a version right from the tray.

Get started

  1. Installer (recommended): download CustomToolsSetup.exe from the latest release and run it. Requires .NET Framework 4.8 (preinstalled on modern Windows).
  2. From source: clone the repo, open CustomTools.slnx in Visual Studio (or msbuild CustomTools.slnx /p:Configuration=Debug), and run CustomTools.exe.

Want to write your own plugin? See PLUGINS.md for a step-by-step guide.
